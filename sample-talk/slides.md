# What is Slidev?

Slidev is a **web-based slides maker** for developers.

- Write content in **Markdown**
- Use **Vue** for interactive demos
- Export to **PDF**, **PNG**, or **PPTX**

# Code blocks

Slidev has first-class code support:

```ts
function greet(name: string) {
  return `Hello, ${name}!`
}
greet('Slidev')
```
